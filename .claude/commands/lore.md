---
description: Add implementation summary to lore folder
---

Add an implementation summary to the `lore` folder in Markdown format, filename: "%Y%m%d-%H%M-lowercase-name.md" (with leading zeros)

Lore should include:
- **Reason**: Why this change was needed
- **Base**: Upstream commit/PR used (e.g., `mongodb/mongoid@abc123`)
- **Alternatives**: Options considered, pros/cons, why final approach was chosen
- **Future**: Possible enhancements, cleanups, extensions
- **Files/Tests**: What changed, coverage added
