## Architecture Notes

### Rails Private API Removal (MONGOID-5831)
Extracted code from `ActiveSupport::ClassAttribute.redefine()` into a custom `__redefine()` method in Traversable to avoid dependency on Rails private API that may change.

### Dirty Tracking Enhancements (MONGOID-4403, 4528)
Added comprehensive dirty tracking methods:
- `attribute_before_last_save(attr)` - Original value before last save
- `saved_change_to_attribute(attr)` - Change during last save
- `saved_change_to_attribute?(attr, from:, to:)` - Check with optional from/to
- `will_save_change_to_attribute?(attr)` - Predict next save changes
- Per-attribute dynamic methods: `#{attr}_previously_was`, `saved_change_to_#{attr}`, etc.

### Embedded Document Batch Optimization (MONGOID-4889)
New methods for optimized batch document insertion:
- `append_many()` - Efficient batch insertion
- `process_incoming_docs()` - Deduplication using Set for O(1) lookup

### ActiveRecord Finder Parity (MONGOID-5418)
Added finder methods: `first!`, `last!`, `second`, `second!`, `third`, `third!`, `fourth`, `fourth!`, `fifth`, `fifth!`, `second_to_last`, `second_to_last!`, `third_to_last`, `third_to_last!`
- Methods without `!` return `nil` when not found
- Methods with `!` raise `Errors::DocumentNotFound`
