# PR #36: Merge Mongoid 9.0.1

**Date:** 2026-02-01
**PR:** https://github.com/activedocument/activedocument/pull/36
**Type:** Upstream sync

## Summary

Merges commits from Mongoid 9.0.1 into ActiveDocument, bringing in bug fixes and improvements from the upstream project while maintaining ActiveDocument's architectural changes.

## Key Changes from Upstream

### Mongoize Improvements (MONGOID-5814, MONGOID-5823)
- `$set` operator in `update_all` now properly calls `mongoize` on field values
- Array update operators (`$push`, `$pull`, `$pop`, `$pullAll`, `$addToSet`) now properly mongoize values
- Fixes type casting issues when using atomic update operators

### Enumerable#sum Compatibility (MONGOID-5786)
- Fixed compatibility with Ruby's `Enumerable#sum` API
- When calling `sum` with both a block and initial value, the initial value is now properly passed through
- Example: `collection.sum(500, &:likes)` now works correctly

### Touch on Custom Fields (MONGOID-5508)
- `touch` method now properly updates custom timestamp fields in addition to `updated_at`
- Works correctly with parent documents that have `touch: true` associations

### Default Scope Merging Fix (MONGOID-5785)
- Fixed bug where default scopes were incorrectly merged with named scopes
- Default scopes now correctly apply without polluting named scope behavior

### Fiber-based Callbacks (MONGOID-5688)
- Child document callbacks now run within fibers for better isolation
- Added `InvalidAroundCallback` error for around callbacks defined without `yield`
- Improves callback reliability for embedded documents

### Transactions API Improvement (MONGOID-5707)
- Uses the MongoDB Ruby Driver's convenient transactions API
- Simplifies transaction handling code

### Database Field Name Handling
- **Note:** PR #37 reverted Mongoid's change (MONGOID-5789) that returned `""` instead of `nil` for missing database field names
- ActiveDocument maintains the original behavior of returning `nil` for the `||` fallback use case

## Files Changed

- 1,008 additions, 517 deletions
- Key areas: `contextual/aggregable/`, `scopable.rb`, `interceptable.rb`, `touchable.rb`
- New error class: `errors/invalid_around_callback.rb`
