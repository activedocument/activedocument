## Architecture Notes

### Query Operators (MONGOID-4906)
The 7.3-stable branch added several MongoDB query operators for embedded document matching:
- `$type` - Type matching with BSON type codes
- `$mod` - Modulo matching with [divisor, remainder] tuples
- `$comment` - Query comments (passed through, always matches)
- Bitwise operators - `$bitsAllSet`, `$bitsAllClear`, `$bitsAnySet`, `$bitsAnyClear`

All are implemented in `lib/active_document/matcher/` and support both position arrays and integer bitmasks.

### Embedded Document Persistence (MONGOID-4982)
Complex fix for handling multiple embedded document operations in a single save. Uses round-robin batching to avoid MongoDB path conflicts when updating, adding, and nesting embedded documents simultaneously.

### Ruby 3.1+ Compatibility (MONGOID-5433)
Replaced deprecated `Time#to_s(format)` with `Time#to_formatted_s(format)` in cacheable code.
