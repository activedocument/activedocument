## Architecture Notes

### Callback Execution Order
The callback execution now follows Rails-compatible patterns:
- Create: `before_save → before_create → [persist] → after_create → after_save`
- Update: `before_save → before_update → [persist] → after_update → after_save`
- Embedded children callbacks execute in proper order via `_active_document_run_child_callbacks`

### Decimal128 Support
- `map_big_decimal_to_decimal128` config option for storage format
- `allow_bson5_decimal128` for BSON 5.0 registry behavior
- Proper numericality validation for Decimal128 values
