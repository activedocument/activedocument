## Architecture Notes

The 7.2-stable branch introduced the refactored embedded matcher system (`MONGOID-4781`) which became the foundation for ActiveDocument's `lib/active_document/matcher/` module. This refactor aligned embedded document matching behavior with MongoDB server queries.

Ruby 3 compatibility (`MONGOID-5123`) was addressed with `ruby2_keywords` in 7.2-stable, but ActiveDocument has modernized this further using Ruby 3.1+ `...` argument forwarding syntax.

## Conclusion

All 25+ significant code changes from 7.2-stable are present in ActiveDocument master. The 4 commits marked as "Not Applicable" relate to deprecated features that were intentionally removed from ActiveDocument's design (QueryCache delegation to driver, :compact option, Symbol field type, Symbol key operators).
