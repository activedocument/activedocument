## Architecture Notes

### Memory Leak Fix (MONGOID-5417)
The `persistence_context.rb` now properly manages client lifecycle:
- `reusable_client?` method identifies when a client can be safely reused
- Non-reusable clients (those created with `.with()` options) are properly closed
- Prevents memory leaks from accumulating option-specific client instances

### Shard Key Processing (MONGOID-5582)
Improved shard key field value extraction:
- Handles embedded document paths with dot notation recursively
- `shard_key_field_value` method traverses nested relationships
- `shard_key_selector_in_db` prefers persisted values when available

### Selector Merge Fix (MONGOID-5642)
The `merge!` method now properly handles both string and symbol versions of `$in` and `$nin`:
- `$in` values are intersected (AND semantics)
- `$nin` values are concatenated and uniqued (OR semantics)

### Take Methods (MONGOID-4547)
ActiveRecord-compatible `take` and `take!` methods:
- `take(limit)` returns one or more documents without specific ordering
- `take!` raises `DocumentNotFound` if no documents exist
- Implemented in Mongo, Memory, and None contexts

## Conclusion

All 15+ significant code changes from 7.5-stable are present in ActiveDocument master. Deprecated features have been resolved by removing them entirely, using the new default behavior without legacy fallbacks.
