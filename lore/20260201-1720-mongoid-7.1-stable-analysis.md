### MONGOID-4988 - Symbol Field Type Warning (NOT APPLICABLE)

**Status: 🚫 Not Applicable**

ActiveDocument removed the Symbol field type entirely in commit `358ce90cd` ("Convert type declarations to symbols - Also remove type: :symbol deprecation warning").

Since Symbol is no longer a valid field type in ActiveDocument, the warning mechanism is unnecessary. Users should use `:string` instead.
