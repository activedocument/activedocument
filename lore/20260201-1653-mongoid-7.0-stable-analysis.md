## Detailed Notes on Key Fixes

### MONGOID-4702 (Not Applicable) - within_box geo_spatial criterion

The `within_box` symbol operator for geospatial queries was **intentionally removed** from ActiveDocument as part of the "baloney removal" refactoring (commit `40a1a1b98`). Symbol key operators like `:field.within_box` were removed in favor of the explicit hash-based API.

```ruby
# Old Mongoid syntax (removed):
Model.where(:location.within_box => [[bottom_left], [upper_right]])

# ActiveDocument syntax (use this instead):
Model.geo_spatial(location: { '$geoWithin' => { '$box' => [[bottom_left], [upper_right]] } })
```

This is a deliberate design decision, not a missing feature.

### MONGOID-4536 - Session accessor naming

This fix renames `session` to `_session` to avoid potential conflicts with user-defined methods. **Already implemented** in ActiveDocument - verified at `lib/active_document/clients/sessions.rb:172`.

### MONGOID-4733 - as_json :compact option

The `:compact` option for `as_json` was **deprecated** in MONGOID-4737 and then **removed** in Mongoid 9.x (commit ca3e02ede). This fix is no longer applicable.

### QueryCache Changes (Removed)

The Mongoid QueryCache was **removed** in MONGOID-5625 because it now delegates to the MongoDB Ruby driver's query cache middleware. All QueryCache-related fixes (MONGOID-4521, MONGOID-4659, MONGOID-4977, MONGOID-4978) are no longer applicable.
