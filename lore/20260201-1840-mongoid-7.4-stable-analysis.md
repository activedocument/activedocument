## Architecture Notes

### Feature Flags Resolution
Mongoid 7.4 introduced many feature flags for behavior changes. ActiveDocument has resolved these by implementing the new (non-legacy) behavior directly, without feature flag toggles.

### Range Query Evolution (MONGOID-5098)
The `__evolve_range__` method now properly handles:
- Endless ranges (1..) → `{ '$gte' => 1 }`
- Beginning-less ranges (..5) → `{ '$lte' => 5 }`
- Exclusive ranges (...) → Uses `$lt` instead of `$lte`

### Cycle Detection (MONGOID-5198)
The `collect_descendants` method uses an `expanded` hash to track visited documents, preventing infinite loops when traversing cyclical embedded document structures.

### Pluck/Distinct Improvements (MONGOID-5028, 5260, 5151)
Major improvements to pluck and distinct:
- Values are now properly demongoized using field type definitions
- Supports `_translations` suffix for localized fields
- `database_field_name` recursively resolves embedded document field aliases

## Conclusion

All 30+ significant code changes from 7.4-stable are present in ActiveDocument master. The feature flags have been resolved to use the new behavior directly without configuration toggles.
